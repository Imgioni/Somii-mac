# Asset and interface prompts

## Main synth art direction

Create the actual front panel of 002 by SPKR as an interactive HTML interface, not a website or promotional image. Smooth matte silicone rotary knobs and fader caps, a matte pale-stone enclosure, graphite oscillator recesses, fine dark silkscreen and restrained burnt-orange active states. Clean, tactile, contemporary audio hardware. Avoid glossy plastic, brushed metal, knurling, neon, dirty textures and decorative animation. Readable labels, deliberate spacing and physically consistent lighting. Place oscillator, filter and envelope controls in the main row, modulation and performance below. Support upper/lower layers and independent Gemini/3rd Wave filter layouts. Exclude FX and patch-browser panels. Keep the 002 and SPKR identity. Use generated reusable raster controls with live HTML interaction, not one flattened screenshot.

## Final control atlas generation prompt

Built-in Imagegen edit, genuine transparent background. The initial metallic draft was superseded after the user specified matte silicone. It is not the final material direction.

Edit this four-cell synth UI control asset atlas. Preserve the exact four-cell arrangement, object centers, approximate sizes and true transparent background. Replace ALL metallic, machined, ridged, knurled and translucent/glossy materials with smooth matte silicone rubber. Top left rotary knob: warm pale stone silicone, smooth subtly domed face, softly rolled edge, NO ridges, NO visible metal, thin charcoal inlaid twelve-o'clock indicator. Top right: identical smooth silicone knob in deep graphite, thin ivory indicator. Bottom left: warm stone silicone horizontal rectangular fader cap with rounded corners and a single thin charcoal horizontal center indicator, perfectly SMOOTH face, NO grooves. Bottom right: opaque desaturated burnt-orange matte silicone rounded rectangular button, no transparency, no glossy highlights. Soft broad diffuse lighting, extremely restrained shading, premium contemporary audio instrument industrial design, clean tactile smooth finishes like high-end silicone control knobs. Use more directly overhead orthographic camera for circular knobs: the faces should be round circles, not angled ellipses; minimal visible sidewall. Objects should appear softly three-dimensional but NOT shiny. No text, labels, ticks, backdrop or borders. Keep four independently reusable controls on genuine transparency.
