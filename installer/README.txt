002 by SPKR
A two-layer bi-timbral synth after the UDO Super Gemini, with a three-slot FX rack.

WHAT GOT INSTALLED
  VST3 plug-in   C:\Program Files\Common Files\VST3\002 By SPKR\
  CLAP plug-in   C:\Program Files\Common Files\CLAP\
  Standalone     the folder you chose, with a Start Menu shortcut
  Patches        Documents\002\Patches (each folder in there is a bank)

FINDING IT IN YOUR DAW
  FL Studio    Options > Manage plugins > Find more plugins, then look for
               "002 | by SPKR" under Generators
  Ableton      Options > Preferences > Plug-ins > Rescan
  Reaper       Options > Preferences > VST > Re-scan
  Studio One   Studio One > Options > Locations > VST Plug-ins > Reset Blocklist

  Put it on an instrument track.

VELOCITY
  Note velocity reaches the sound through VCA DYNAMICS, which is ON by default.
  A patch saved with DYNAMICS OFF plays every note at the same level; flip it on.

THE RIBBON
  Touch it anywhere and slide: right or up bends pitch up, left or down bends it
  down, from wherever your finger landed.
  To play it from a MIDI controller, either send CC 2 (the middle of the range is
  no bend), or link any knob to the "Ribbon" parameter. In FL Studio: open the
  plug-in menu > Browse parameters, right-click "Ribbon" > Link to controller,
  then move your knob.

NOTES
  The plug-in window needs the Microsoft Edge WebView2 runtime, which comes with
  Windows 11 and current Windows 10. If the window is blank, install it from
  https://developer.microsoft.com/microsoft-edge/webview2/

UNINSTALLING
  Settings > Apps > Installed apps > 002 by SPKR, or the Start Menu shortcut.
