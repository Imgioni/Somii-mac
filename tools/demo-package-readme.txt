002 by SPKR 0.3.0 - Windows demo/test package
==========================================

This build adds the FX rack: three effect slots (serial or parallel), 21 effects,
and a layer-mix fader under each slot.

This is an unrestricted demo/test build. No time limit or demo audio
interruptions are implemented.

INSTALL VST3
Copy the whole "VST3/002 By SPKR" folder into:
  C:\Program Files\Common Files\VST3
so you end up with ...\VST3\002 By SPKR\002 by SPKR.vst3
Then rescan plugins in your DAW. It shows up as "002 | by SPKR". Restart the DAW if an older version
(it was called Geminus) was loaded, and remove any old Geminus.vst3 copy.

INSTALL CLAP
Copy CLAP/002 by SPKR.clap into your host's CLAP plugin folder, normally:
  C:\Program Files\Common Files\CLAP

STANDALONE
Run Standalone/002 by SPKR.exe. Choose your audio/MIDI device under Options.

REQUIREMENTS
Windows x64 and Microsoft Edge WebView2 Evergreen Runtime. If the interface
does not open, install WebView2 from Microsoft and restart the application.
All interface assets are embedded; no source folder or local server is needed.

SHA256SUMS.txt lists checksums for the three freshly rebuilt binaries.
